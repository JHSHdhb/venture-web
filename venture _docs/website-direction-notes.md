# Website Direction Notes

## Site Role

The new Venture site should be positioned as a GEO authority source and brand fact system, not simply another SEO inquiry site.

It should also be explained to the client as Venture Electronics' AI-readable official source / canonical source. In this project, canonical source means a brand/entity authority source, not a technical `rel=canonical` SEO tag.

It should:

- clarify Venture Electronics as the mother brand
- explain Venture PCB / Venture PCBA as keyword and service-entry concepts
- make public-safe facts easy for AI systems to understand and cite
- provide a reusable front-end layer for facts, FAQs, cases, capabilities, claim boundaries, and evidence-backed content
- explain how Venture's existing and future sites/channels relate to each other

## Problem To Solve

The initial client concern was that AI and Google appear to understand Venture assets inconsistently:

- ChatGPT surfaced `venture-pcba.com` for Venture Electronics instead of the main `venture-mfg.com` site.
- Google ranked `venture-pcba.com` above `venture-mfg.com` for "Venture PCB".
- The client considered whether Venture Electronics should become Venture PCB as the main brand.

Recommended answer:

- Keep Venture Electronics as the mother brand.
- Use Venture PCB / Venture PCBA as keyword and service-entry concepts.
- Build the new GEO site as the official explanation layer that clarifies the relationship among Venture Electronics, `venture-mfg.com`, `venture-pcba.com`, PCBA, EMS, PCB Fabrication, YouTube, LinkedIn, blog assets, and social profiles.

## Positioning

- Primary sales entry: PCBA / PCB Assembly
- Strategic brand ceiling: EMS / Box Build / one-stop manufacturing partner
- Differentiator: supply-chain integration, sourcing, engineering coordination, quality supervision, and human project ownership
- Supporting service: PCB Fabrication

## Homepage Direction

The homepage should avoid reducing Venture to "PCB factory." It should signal:

1. Venture Electronics as a China PCBA and EMS manufacturing partner.
2. PCBA as the immediate project-entry point.
3. EMS / Box Build as the high-value manufacturing path.
4. DFM, BOM review, sourcing, testing, and quality control as trust proof.
5. A human, accountable alternative to automated low-cost platforms.

## Canonical Source Logic

The reference report supports this framing:

- Multiple websites and business lines are normal in industrial and electronics groups.
- The problem is not website count; the problem is unclear relationship mapping.
- A mother-brand or group-level official source can define brands, sub-sites, services, product lines, regional pages, and social channels.
- Venture should use the new GEO site to establish the future standard wording even if old sites and external content channels are not migrated immediately.

Implementation ideas:

- Add an "Official Resources" page listing the main site, PCBA-focused site, YouTube, LinkedIn, Facebook/Instagram where applicable, and blog/content channels.
- Add "Venture Electronics vs Venture PCB / Venture PCBA" content.
- Add schema `sameAs` links for approved official assets.
- Add a Brand Entity Alignment Brief for any SEO, YouTube, blog, or social vendor.

## Claim Handling

Every page should treat claims as one of:

- public-safe
- evidence-needed
- partner-network wording only
- internal-only
- prohibited

Do not publish certification, factory scale, customer-name, production-volume, or audit-readiness claims without evidence.
